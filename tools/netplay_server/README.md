# Netplay-сервер

Комнату держит этот процесс, не телефон. Оба игрока в игре жмут «Подключиться к серверу». Кнопка «Хост» на месте и по-прежнему слушает свой порт.

```
docker compose up --build
```

Наружу открыт порт 7777. С той же машины в поле IP пишется `127.0.0.1`, порт `7777`. Второй компьютер пишет LAN-адрес машины, где запущен контейнер, и тот же порт.

Сервер принимает двоих и повторяет строки протокола сопернику как есть (`ping`, `pong`, `hello`, `move`, `resign`, `quit`). Пока второго ещё нет, `ping` первого получает `pong` от сервера, чтобы ожидание не срывалось по таймауту. Если клиент молчит, сервер сам шлёт `ping`. Если один отвалился, второму уходит строка `opponent_left`.
